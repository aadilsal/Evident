# Evident web

The map UI, gallery, benchmarks and supported-stacks pages: a Next.js **static export** ([ADR-0008](../docs/adr/0008-static-web-on-vercel-api-on-one-server.md)). The same build runs on Vercel and inside the Python package for `evident open`.

```bash
npm ci
npm run dev                  # http://localhost:3000; gallery and local data work without an API
NEXT_PUBLIC_API_URL=http://localhost:8000 npm run dev   # with the API (needs EVIDENT_CORS_ORIGINS)
npm run build                # static site in out/
npm run build:bundle         # build, then copy into engine/src/evident/webui for `evident open`
```

Before a commit: `npm run check:generated && npm run format:check && npm run lint && npm run typecheck && npm test`.

- `src/lib/`: graph queries (a port of the engine's `query.py`, checked against engine goldens), view builders, ELK layout, URL state, data sources.
- `src/components/map/`: the canvas, evidence panel, rail, top bar and search palette.
- `src/styles/tokens.css` is generated from [DESIGN.md](../DESIGN.md) (`npm run tokens`); `src/lib/schema.ts` from the graph schema (`npm run gen:types`). Don't edit either by hand.
- `public/data/gallery/` is generated by `engine/scripts/build_gallery.py`; benchmark data is copied in at build time.
